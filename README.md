# حورية مول — Houria Mall

موقع حجز المنتجات بمقدم (فودافون كاش / إنستاباي) والاستلام من الفرع، مع لوحة تحكم خاصة.

- الموقع: https://houriamall.shop
- لوحة التحكم: https://houriamall.shop/admin

## التشغيل محلياً
```bash
npm install
npm run dev
```

## النشر
أي push على `main` بيبني الموقع وينشره تلقائياً على GitHub Pages (`.github/workflows/deploy.yml`).
